# RTH Open Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (this session: inline). Steps use checkbox syntax.

**Goal:** Split the 9:15 job back into a Gap prelayer; rank cash-secured puts from live option chains at the 9:30 ET cash open.

**Architecture:** Premarket writes `snapshot.csv` only (one Finviz export, no chains). A new `rth` job at 09:30 ET reads that snapshot plus overnight RV, pulls unthrottled options JSON, writes `snapshots/.../rth/`, comments the standing issue, and fires the analyst webhook. The Cloudflare `*/15` clock already ticks 09:30.

**Tech Stack:** Python 3.11, pytest, GitHub Actions, Cloudflare Worker.

## Global Constraints

- `/export/*` one call per 60 seconds; options JSON unthrottled
- Morning never calls `/export/quote`
- 9:15 is not a trade list; 9:30 is
- Session clock is `America/New_York`
- Analyst webhook fires after the RTH commit, not premarket
